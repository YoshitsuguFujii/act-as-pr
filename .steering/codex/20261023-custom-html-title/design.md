# 設計

## 実装アプローチ

CLI で `--title` の値を受け取り、レンダリングデータへ渡す。テンプレートは値がある場合にそれを使用し、未指定時は従来の式を使う。watch の再生成でも同じ値を保持する。

## 変更するコンポーネント

- `main.go`: 引数解析と snapshot への伝播
- `watch.go`: watch の初回表示と再生成への伝播
- `viewer.html`: タイトルの描画
- テストと README

## データ構造

レンダリングデータと watch サーバーに任意のタイトル文字列を保持する。永続データ構造は変更しない。

## 影響範囲

CLI とブラウザのタブ名に影響する。未指定時は互換の値を保ち、`html/template` の自動エスケープで入力をテキストとして扱う。性能への影響は軽微。
