# 差分ファイルの固定見出し

## 機能

長い差分をスクロールしてファイル見出しが画面上端に達したら、表示中のファイルパスとコピーボタンを含む見出しを上端に保つ。

## ユーザーストーリー

レビュー中の利用者として、長い差分の途中でも現在読んでいるファイルを見分け、パスをコピーしたい。

## 受け入れ条件

- 見出しはファイルの先頭では通常位置に表示され、スクロール後は画面上端に残る。
- 次のファイルへ進むと固定表示も次のファイルに切り替わる。
- 固定表示中もファイルパス、コピーボタン、Viewed 操作を利用できる。
- Files changed、All changes、コミット差分の共通表示に適用する。
- ファイル末尾を越えて、別ファイルの見出しが誤って残らない。

## 制約

- 自己完結 HTML と CSP を維持し、外部依存を追加しない。
- 未追跡の `data/` は変更しない。
- 添付された GitHub PR の２枚の画像を表示仕様の根拠とする。
