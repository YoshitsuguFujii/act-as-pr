# 設計

## 実装アプローチ

共通 `diffView` の各 `details.file-card` にある `summary.file-header` をスクロール位置に追従させる。見出しはカード内に留まり、次のカードへ移ると切り替わる。

## 変更コンポーネント

- `viewer.css`: 見出しの位置、重なり順、カードのクリッピングを調整する。
- ブラウザテスト: 位置の変化とファイル間の切り替わりを確認する。

## データ構造

変更なし。

## 影響範囲

全差分ビューで同じテンプレートを使う。テーブルの横スクロール、折りたたみ、パスコピーと Viewed 操作は維持する。CSS のみの変更で Git やサーバーの処理には影響しない。

## 計画レビュー

- Blocking: `file-card` の `overflow: hidden` は固定配置の基準になるため、見出しが追従できるよう変更する。
- Blocking: 他のカードを越えて見出しが残らないことを実ブラウザで確認する。
- Non-blocking: 狭い画面では見出しが折り返すため、表示崩れをスクリーンショットで確認する。
