# 行内差分の強調

## 機能
対応する削除行と追加行で、変更された文字の範囲を Unified と Split の両表示で強調する。

## ユーザーストーリー
レビュー担当者として、行のどの文字が変わったかをすぐに読み取りたい。

## 受け入れ条件
- `abcde` から `abccd` への変更では、共通の文字と変更された文字を見分けられる。
- 1 行内の複数箇所の変更も別々に強調される。
- 対応する相手のない追加行・削除行は従来の行表示を維持する。
- Unified、Split、各差分タブで同じ強調が表示される。
- HTML を含む差分テキストは実行されない。

## 制約
Git への書き込みや外部通信を追加しない。巨大な行の比較は計算量を制限する。
