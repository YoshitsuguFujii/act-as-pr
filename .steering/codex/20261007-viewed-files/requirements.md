# Viewed ファイル

## 機能とユーザーストーリー

ローカル PR の差分を読む利用者が、確認済みファイルを Viewed にして残りの確認対象を把握できる。

## 受け入れ条件

- Files changed、All changes、各コミット差分で、ファイルごとに Viewed を切り替えられる。
- Viewed にするとその差分を折りたたみ、解除すると再び表示する。ナビゲーションには確認済みの状態を示す。
- 各差分表示に確認済み件数を表示する。別の差分表示の同名ファイルには状態を混同しない。
- watch の自動再読み込みでは未変更ファイルの Viewed を復元し、内容が変わったファイルは未確認に戻す。
- スナップショットの同一ページ内でも切り替えられる。ブラウザが sessionStorage を許す場合は同一 URL の再読み込み後も復元する。
- README の画像とインストール案内を更新し、`v0.3.0` を公開して `@latest` から取得できるようにする。

## 制約

- GitHub やリポジトリへレビュー状態を送信・書き込みしない。
- 自己完結 HTML と CSP を保ち、外部依存を追加しない。
- 未追跡の `data/` は変更しない。

## 確認済みソースと対象範囲

- GitHub Docs「Reviewing proposed changes in a pull request」の Viewed 説明を確認した。
- 対象はローカルビューアーの全差分表示。GitHub 側の Viewed 状態との同期は対象外。
