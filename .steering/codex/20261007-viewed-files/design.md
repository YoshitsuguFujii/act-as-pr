# 設計

- 共通 `diffView` にファイルごとのチェックボックスと表示単位ごとの進捗を追加する。
- Viewed の操作は `details` の開閉操作から独立させる。切り替え時の折りたたみと解除をブラウザで処理する。
- 各ファイルの差分内容から安定した指紋を生成し、確認済み状態とともに保存する。watch の更新後、指紋が一致する場合だけ復元する。
- 既存の `sessionStorage` にある UI 復元処理を拡張する。保存できない環境でも現在のページで操作できる。
- 変更コンポーネントは HTML テンプレート、CSS、JavaScript、レンダラー、テスト、README。
- データ構造は永続化 DB を追加しない。ブラウザのセッション状態のみを使う。
- 差分の HTML 出力サイズは指紋分だけ増える。パスや差分は既存のテンプレートエスケープを経由し、外部送信はしない。

## 計画レビュー

- **Blocking 対応**: ファイル名のみで復元すると差分更新後も Viewed が残るため、内容指紋を保存・照合する。
- **Blocking 対応**: `details` 内の操作で見出しクリックが伝播すると意図せず再展開するため、Viewed 操作を独立させる。
- **Non-blocking**: スナップショットは毎回異なる一時 URL を生成する。別の実行間での確認状態共有は行わない。
