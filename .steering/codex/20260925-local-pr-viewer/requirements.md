# Local PR viewer requirements

## 機能
`act-as-pr <base>` は HEAD と base の merge base からの差分を、自己完結 HTML に描画して既定ブラウザで開く。GitHub の Files changed に近い閲覧体験を提供する。

## ユーザーストーリー
開発者として、リポジトリの任意のサブディレクトリからコマンドを実行し、ローカル変更を PR のように確認したい。

## 受け入れ条件
- base の検証、merge base、変更ファイルと行統計が正しい。
- 追加・変更・削除・リネーム・バイナリ・特殊ファイル名を表示できる。
- Unified/Split、ファイル移動、折りたたみ、明暗テーマがブラウザで機能する。
- HTML はオフラインで動作し、差分由来の HTML/JS を実行しない。
- 通常実行で Git リポジトリの状態を変えない。
- テスト、ビルド、一時リポジトリでのブラウザ実検証が成功する。

## 制約
Go 標準ライブラリ中心、サーバー・ネットワーク・GitHub 連携なし。出力は OS 一時領域。引数なしで安全に base を決められない場合は usage を表示する。レビュー操作は作らない。
