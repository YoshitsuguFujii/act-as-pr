# Viewer navigation

## 機能
長い差分を読んでいるときだけ右下にページ先頭へ戻るボタンを表示する。Files changed / Commits / All changes とコミット一覧・詳細の切り替えをブラウザの戻る・進むでたどれるようにする。

## ユーザーストーリー
差分を下まで読んだ利用者として、すぐタブへ戻りたい。コミットを開いた後は、ブラウザの戻る操作で見ていた一覧や前のタブへ戻りたい。

## 受け入れ条件
- ページ上部では先頭へ戻るボタンが表示されず、十分下にスクロールすると右下に上矢印だけを表示する。クリックするとページ先頭へ戻り、再び非表示になる。画面上に日本語ラベルを置かない。
- キーボードとスクリーンリーダーからボタンを操作できる。light/dark と狭い画面でも読める。
- タブ切替、コミット詳細、一覧へ戻る操作はブラウザ履歴に記録される。戻る・進むでタブと選択コミットが復元される。
- 同じ画面を再度選んでも余分な履歴を追加しない。ファイルへのアンカーリンクも引き続き動く。
- snapshot の file:// と watch の両方で動き、watch の自動更新後も表示状態を維持する。
- Git 比較、read-only/security、既存機能を変えない。

## 制約
既存の埋め込み HTML/CSS/JS と Go テストを用いる。サーバー・依存・外部通信・レビュー機能を追加しない。完了後にユーザーから commit/push と最新版を配布するための tag 作成が明示的に依頼された。
