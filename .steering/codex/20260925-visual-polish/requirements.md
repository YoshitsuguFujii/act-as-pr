# Visual polish requirements

## 機能
ローカル PR 差分ビューアを、公開されている GitHub の Files changed 画面に近い情報密度と読みやすさへ整える。

## ユーザーストーリー
開発者として、通常のデスクトップ幅で多数の変更ファイルを探し、差分を快適に読みたい。base と compare の向きも迷わず確認したい。

## 受け入れ条件
- 1440×900 程度のデスクトップ幅を有効活用し、差分に十分な横幅を割く。
- base: main / compare: feature のように方向が明確である。
- ファイル一覧は多数のパスを見つけやすく、長い一覧は独立してスクロールできる。
- 行番号・hunk・追加・削除がライトとダークの両方で読める。
- Unified/Split、アンカー、折りたたみ、安全性は維持する。
- 既存テストとブラウザスモークテストが通る。

## 制約
新しい製品機能やレビュー操作は追加しない。CSS と表示上の整理に限定し、独自の実装を維持する。参考は公開 GitHub PR の Files changed 画面。
