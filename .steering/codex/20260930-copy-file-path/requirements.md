# ファイルパスのコピー

## 機能とユーザーストーリー

ローカルPRプレビューの各ファイル見出しから、表示中のリポジトリ相対パスをコピーする。レビュー中にファイル位置を共有したい利用者が、パスを選択せずに取得できる。

## 受け入れ条件

- Files changed、All changes、コミット差分の各ファイル見出しにコピーボタンを表示する。
- 押すとその見出しのパスがコピーされ、差分の開閉状態は変わらない。
- コピーの成功・失敗を利用者に伝える。
- スナップショットの `file://` 表示でも使える。

## 制約

- 既存の自己完結HTML、CSP、外部通信なしの構成を保つ。
- 未追跡の `data/` は変更しない。
